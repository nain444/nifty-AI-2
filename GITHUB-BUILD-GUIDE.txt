🎯 STEP-BY-STEP GUIDE:

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: Install Git (if not installed)                                      │
└──────────────────────────────────────────────────────────────────────────────┘

1. Go to: https://git-scm.com/download/win
2. Download and install Git for Windows
3. Use default settings during installation
4. Restart this process after installation


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: Push Code to GitHub                                                 │
└──────────────────────────────────────────────────────────────────────────────┘

1. Double-click: PUSH-TO-GITHUB.bat
2. Enter your GitHub credentials when asked
3. Wait for upload to complete


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 3: Build APK on GitHub                                                 │
└──────────────────────────────────────────────────────────────────────────────┘

1. Go to: https://github.com/nain444/nifty-AI-2
2. Click "Actions" tab at the top
3. Click "Build Android APK" on the left
4. Click "Run workflow" button (green button on right)
5. Click "Run workflow" again to confirm
6. Wait 5-10 minutes for build to complete


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 4: Download APK                                                        │
└──────────────────────────────────────────────────────────────────────────────┘

1. After build completes, scroll down to "Artifacts"
2. Click "NIFTY-AI-Trader-Debug" to download
3. Extract the ZIP file
4. You'll get: app-debug.apk


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 5: Install on Phone                                                    │
└──────────────────────────────────────────────────────────────────────────────┘

1. Copy app-debug.apk to your phone
2. Open the file on your phone
3. Tap "Install"
4. Enable "Install from unknown sources" if asked
5. Done! App appears on home screen

⚠️ TROUBLESHOOTING:

Problem: Git not installed
Solution: Download from https://git-scm.com/download/win

Problem: GitHub authentication failed
Solution: Use GitHub Desktop app instead (easier)
         Download: https://desktop.github.com/

Problem: Repository doesn't exist
Solution: Create it first at https://github.com/new
         Name: nifty-AI-2
         Make it Public

Problem: Build failed on GitHub
Solution: Check the Actions tab for error logs
         Usually fixes itself on retry

═══════════════════════════════════════════════════════════════════════════════

💡 ALTERNATIVE: Use GitHub Desktop (Easier!)

1. Download: https://desktop.github.com/
2. Install and sign in to GitHub
3. File → Add Local Repository → Select nifty-ai-mobile folder
4. Publish repository
5. Go to GitHub website → Actions → Run workflow
