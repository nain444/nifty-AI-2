STEP 1: Download GitHub Desktop
────────────────────────────────────────────────────────────────────────
→ Go to: https://desktop.github.com/
→ Download and install it
→ Sign in with your GitHub account (nain444)

⏱️ Time: 3 minutes


STEP 2: Publish Your Code
────────────────────────────────────────────────────────────────────────
→ Open GitHub Desktop
→ Click: File → Add Local Repository
→ Browse to: C:\Users\navin\project1\nifty-ai-mobile
→ Click: "create a repository" if asked
→ Click: "Publish repository" button (top right)
→ Name: nifty-AI-2
→ Click: "Publish repository"

⏱️ Time: 2 minutes


STEP 3: Build APK on GitHub
────────────────────────────────────────────────────────────────────────
→ Go to: https://github.com/nain444/nifty-AI-2
→ Click: "Actions" tab
→ Click: "Build Android APK" (left side)
→ Click: Green "Run workflow" button (right side)
→ Click: "Run workflow" in dropdown
→ Wait for green checkmark ✅

⏱️ Time: 5-10 minutes (automatic)


STEP 4: Download APK
────────────────────────────────────────────────────────────────────────
→ Click on the completed workflow run
→ Scroll down to "Artifacts"
→ Click: "NIFTY-AI-Trader-Debug" to download ZIP

⏱️ Time: 1 minute


STEP 5: Install on Phone
────────────────────────────────────────────────────────────────────────
→ Extract the ZIP file
→ Copy app-debug.apk to your phone
→ On phone: Settings → Security → Enable "Unknown Sources"
→ Open the APK file and install
→ Open app and tap "START SIGNALS"

⏱️ Time: 3 minutes
